Política de privacidad

Qué información se usa en este sitio, y qué no.

Resumen

Este es un sitio de herramientas gratuitas (calculadoras y utilidades) sin backend propio, sin base de datos y sin cuentas de usuario. No pedimos registro para usar ninguna herramienta, y no recopilamos información personal para crear perfiles de usuarios.

Almacenamiento local del navegador (localStorage)

Este sitio usa localStorage, una función estándar de tu navegador para guardar datos pequeños directamente en tu dispositivo (no en un servidor). Lo usamos únicamente para recordar tu preferencia de idioma (español o inglés) entre visitas. Puedes borrar este dato en cualquier momento limpiando los datos de navegación o las cookies/almacenamiento del sitio desde la configuración de tu navegador.

APIs de terceros usadas por algunas herramientas

Algunas herramientas del sitio hacen llamadas directas desde tu navegador a servicios públicos de terceros para funcionar. No pasan por ningún servidor propio. Como parte del funcionamiento normal de esos servicios, es posible que reciban tu dirección IP y otros datos técnicos habituales de cualquier solicitud web:

  • Conversor de divisas: usa exchangerate-api.com para obtener tasas de cambio actualizadas.
  • Radio online: usa el directorio abierto Radio-Browser para listar y reproducir emisoras de terceros.
  • TV en vivo: usa el reproductor embebido oficial de YouTube para mostrar canales que transmiten en vivo desde sus propios canales oficiales.

El uso de estos servicios está sujeto a las políticas de privacidad de cada proveedor, no a las de este sitio.

Ko-fi (botón "invítame un café")

Los botones "☕ Invítame un café" te llevan a ko-fi.com, un sitio de terceros. Cualquier dato que compartas ahí (por ejemplo al hacer una donación vía PayPal) es manejado por Ko-fi y PayPal bajo sus propias políticas de privacidad. Este sitio no recibe ni almacena esa información.

Publicidad (si se activa en el futuro)

Actualmente este sitio no muestra anuncios. Si en el futuro activamos publicidad (por ejemplo mediante Google AdSense), los anuncios podrían usar cookies u otras tecnologías similares para personalizar el contenido mostrado, según las políticas de publicidad de Google. Más información en policies.google.com/technologies/ads. Actualizaremos esta página cuando eso ocurra.

Analítica

Este sitio no usa actualmente ninguna herramienta de analítica de terceros (como Google Analytics). Si esto cambia en el futuro, se reflejará en esta política.

Contacto

No hay un correo de contacto público asociado a este proyecto por ahora. Puedes contactar a través de la página de Ko-fi.

Cambios a esta política
