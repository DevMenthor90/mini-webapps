¿De dónde salen las tasas de cambio?

Este conversor usa una API pública gratuita de tipo de cambio que cubre más de 160 monedas del mundo, incluyendo el peso colombiano y otras monedas latinoamericanas. Las tasas se actualizan aproximadamente cada 24 horas.

¿De dónde vienen las tasas de cambio?

Las tasas provienen de una API pública gratuita que agrega datos de mercado, cubriendo más de 160 monedas incluyendo el peso colombiano.

¿Por qué la tasa que veo aquí es distinta a la de mi banco?

Esta es la tasa de referencia del mercado interbancario, sin el margen o comisión que aplican bancos, casas de cambio o tarjetas al hacer la conversión real.

¿Con qué frecuencia se actualiza el tipo de cambio?

Las tasas se actualizan aproximadamente cada 24 horas, por lo que la hora mostrada indica la última actualización disponible.
